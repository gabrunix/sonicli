# Changelog

All notable changes to SoniCLI will be documented here.

## [0.1.0] - 2026-08-31

### Added
- Interactive terminal music search powered by yt-dlp.
- fzf result selector.
- mpv audio playback with IPC control.
- Lightweight low-flicker player screen.
- Linux and Termux-aware installer.
- Initial Debian and Termux packaging templates.
- CLI flags for help, version, and direct search.
