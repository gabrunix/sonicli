# Contributing to SoniCLI

Thanks for helping improve SoniCLI.

## Development setup

```bash
git clone https://github.com/gabrunix/sonicli.git
cd sonicli
./install.sh
```

Run syntax checks before opening a pull request:

```bash
bash -n bin/sonicli src/*.sh install.sh uninstall.sh
```

Keep changes focused, document user-visible behavior, and update `CHANGELOG.md` when appropriate.
